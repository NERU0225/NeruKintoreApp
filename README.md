# 筋トレ

部位（腕・肩・胸…）を登録し、日ごとにどの部位を組み合わせるかを決めて順番に回すアプリ。
部位ごとにチェックを付け、**全部チェックできなかった日は、その組み合わせが翌日にずれ込みます。**
ストレッチなど毎日やることは別枠でチェックします。
サーバーは使わず、データは自分の端末（ブラウザ）の中だけに保存されます。

## ずれ込みの動き

ルーティンが「腕・肩 → 胸・背中 → 腹筋・脚」の場合：

| | 月 | 火 | 水 | 木 | 金 |
|---|---|---|---|---|---|
| 全部やった | 腕・肩 | 胸・背中 | 腹筋・脚 | 腕・肩 | 胸・背中 |
| 火曜は胸だけ | 腕・肩 ✓ | 胸・背中 1/2 未実施 | **胸・背中** | **腹筋・脚** | **腕・肩** |

組み合わせの部位が全部チェックされた日だけ順番が進みます。曜日には固定されません。
毎日の項目（ストレッチなど）は、やらなくても順番に影響しません。

## 公開のしかた（GitHub Pages）

家計簿と同じ手順です。リポジトリだけ別に作ります（例：`kintore`）。

1. GitHub で **New repository** → 名前 `kintore` → **Public** → Create
2. **uploading an existing file** から次の6つをアップロード → Commit
   - `index.html` / `manifest.json` / `sw.js` / `icon-180.png` / `icon-192.png` / `icon-512.png`
3. **Settings → Pages** → Deploy from a branch → `main` / `/ (root)` → Save
4. 1〜2分で `https://<ユーザー名>.github.io/kintore/` が開けるようになります
5. **Safari** で開き、共有ボタン →「ホーム画面に追加」

> **家計簿と同じアカウントで公開する場合の注意**
> 2つのアプリは同じ配信元（`<ユーザー名>.github.io`）になり、オフライン用のキャッシュ置き場を共有します。
> いまの家計簿の `sw.js` は、更新時に**自分以外のキャッシュをすべて消す**作りなので、
> 家計簿を更新するとこのアプリのキャッシュも消え、次に**通信ありで開くまで**機内モードで起動できなくなります。
> 家計簿の `sw.js` の削除条件を `k.startsWith('kakeibo-')` に絞ると解消します（このアプリ側は対応済み）。
> 保存データ（localStorage）はキー名を `kintore:` で分けてあるので、混ざったり消えたりはしません。

## 更新のしかた

`index.html` と `sw.js` を差し替えて Commit。通信がある状態で開くと新しい版に切り替わり、
「vX に更新しました」と出ます。記録したデータは消えません。

> `index.html` の `APP_VERSION` と `sw.js` の `CACHE`（`'kintore-' + 'vX'`）の番号を必ず揃えてください。

## 使い方

### 設定
- **部位**：腕・肩・胸など1つずつ登録。種目（アームカール 10回×3 など）は部位ごとに書く
- **ルーティン**：「＋ 日を追加」で、その日にやる部位を選ぶ（選んだ順に並ぶ）。▲▼で回す順番を入れ替え
- **毎日やること**：ストレッチなど。追加した日から毎日チェック欄が出る
- **次にやるメニュー**：順番を飛ばしたい時や、途中から始めたい時に選び直す
- **バックアップ**：`kintore.json` の書き出し／読み込み

### ホーム
- **今日のメニュー**：部位ごとのチェックと種目。「まとめて実施」で全部チェック
- **毎日やること**：項目ごとのチェック
- 今週・今月の実施回数、連続日数
- **週の一覧**（月曜はじまり）。右の○で全部チェック／全部外す。一部だけの日は「1/2」と出る

### カレンダー
月表示。✓＝実施、×＝未実施。小さな緑の点＝毎日の項目を全部やった日。日付をタップで詳細とチェック。

### チェックについて
- 付けられるのは**今日と過去の日**だけ
- 過去の日の「実施／未実施」が変わると、それ以降の予定が組み直されます（確認が出ます）
- 部位やルーティンを変えた日（または使い始めた日）より前の記録は、表示だけになります

### v0.1 から更新した場合
「腕と肩」のような名前は自動で「腕」「肩」の部位に分けて引き継ぎます。これまでの実施・未実施の記録も残ります。
毎日の項目は空なので、設定から追加してください。

## データについて

- 保存先はブラウザの `localStorage`（キー `kintore:data`）
- Safari はしばらく開かないサイトのデータを消すことがあるので、ときどき書き出しておくと安心です
- 最後の書き出しから14日たつと、画面上部に案内が出ます
